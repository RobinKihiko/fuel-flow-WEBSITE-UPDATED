# Fuel Flow Pro – Landing Page

Static landing page for Fuel Flow Pro (fuel station management for Kenya). Powered by [E-Digital](https://www.edigital.co.ke/).

## Files
- `index.html` – the full site (HTML, CSS and JS in one file)
- `og-image.jpg` – social sharing image (1200x630)
- `sitemap.xml`, `robots.txt` – SEO files

## Before going live
1. Replace `https://www.fuelflowpro.co.ke` with your real domain in `index.html`, `sitemap.xml` and `robots.txt`.
2. Replace the sample testimonials with real customer quotes.
3. The "AI plan" feature needs a backend call to an AI model. Until it is connected, it shows a message that points visitors to WhatsApp.

## Deploy
Any static host works (GitHub Pages, Cloudflare Pages, Netlify). For GitHub Pages: Settings > Pages > deploy from the `main` branch, root folder.
